Cuidados

Aspira sin cepillo giratorio. Gira el tapete cada pocos meses para que el desgaste sea parejo. Limpia derrames de inmediato con un paño húmedo y agua fría. Para limpieza profunda, recomendamos lavado profesional en seco.
